# Kazakhstan Housing Prices Analysis

Анализ цен на жильё в Казахстане на основе официальной статистики (Бюро национальной статистики АСПиР РК), с акцентом на Алматы.

Источник данных: [Finratings.kz](https://finratings.kz/data/housing/) — данные БНС РК в готовом CSV-формате (новостройки, вторичка, аренда).

## Структура данных

- Полная история (2001–2025) доступна только для Казахстана в целом (`region = 'KZ'`).
- Для отдельных городов (включая Алматы) доступен только срез на 2025 год — истории по годам для конкретных городов в открытых данных нет.

## Бизнес-вопросы

- Как менялись цены на жильё в Казахстане за последние 24 года?
- Как Алматы сравнивается с другими городами Казахстана по цене новостроек, вторички и аренды в 2025 году?

## Как запустить

1. Скачать CSV с finratings.kz/data/housing/ (new-price, resale-price, rent-price), положить в `data/`.
2. Создать базу `almaty_housing` в PostgreSQL.
3. Установить зависимости: `pip install pandas sqlalchemy psycopg2-binary`.
4. Задать пароль: `$env:PGPASSWORD="ваш_пароль"`.
5. Запустить: `python load_data.py`.
6. Выполнить запросы из `sql/01_city_comparison.sql` в pgAdmin.

## Техническая заметка

CSV-файлы с Finratings.kz используют `;` как разделитель столбцов, а не запятую — при чтении в pandas нужно указать `sep=";"`.
